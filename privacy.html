Kebijakan ini menjelaskan bagaimana aplikasi Android Ayat Dulu (com.hijrahmode.app; nama Inggris: Ayah First; nama sebelumnya: Hijrah Mode) memperlakukan data Anda. Ayat Dulu dikembangkan oleh perorangan, dr. Bambang Hendra S, Kotamobagu, Indonesia.

Ringkasnya
  • Kami tidak mengumpulkan, mengirim, menjual, atau membagikan data pribadi apa pun.
  • Tidak ada akun, iklan, analytics, maupun server. Aplikasi ini tidak memiliki izin akses internet.
  • Semua yang dicatat aplikasi disimpan di HP Anda saja dan terhapus saat aplikasi dihapus.

1. Data yang disimpan di HP Anda

Agar aplikasi berfungsi, data berikut disimpan di penyimpanan internal HP Anda dan tidak pernah dikirim ke luar HP:

  • Pengaturan: daftar aplikasi yang Anda pilih untuk diberi gerbang, mode gerbang, target harian, waktu bebas, ukuran huruf, bahasa terjemah, transliterasi, tema, dan Mode tenang.
  • Progres belajar: posisi bacaan ayat, tingkat Jalur Hijaiyah, dan jumlah khatam.
  • Statistik lokal: jumlah ayat dan kartu yang dibaca, gerbang yang selesai, jumlah tiap jalan keluar yang dipakai, hari aktif, Taman Hijrah, dan streak.
  • Mode terjemah saja: status aktif dan tanggal berakhir yang Anda isi sendiri.
  • Catatan gerbang hari ini untuk layar Bantuan: jumlah gerbang yang tampil dan yang dilewati per alasan (waktu bebas, tempat tidak layak), jam kejadian terakhir, dan jam layanan terakhir tersambung. Tanpa nama aplikasi; hitungan direset setiap hari.

Cadangan data (opsional): bila Anda mengetuk Pengaturan › Simpan cadangan, data di atas (kecuali catatan gerbang harian) disalin ke satu file JSON di tempat yang Anda pilih sendiri lewat pemilih file Android, misalnya folder Download atau Google Drive. Aplikasi tidak mengirim file itu ke mana pun; bila Anda memilih layanan awan, file itu tunduk pada kebijakan layanan tersebut. File hanya dibaca kembali saat Anda memilih Pulihkan dari cadangan.

Ayat Dulu tidak menyimpan riwayat aplikasi yang Anda buka. Anda dapat menghapus seluruh data ini kapan saja lewat Pengaturan Android › Aplikasi › Ayat Dulu › Penyimpanan › Hapus data, atau dengan meng-uninstall aplikasi.

2. Layanan Aksesibilitas (AccessibilityService)

Untuk apa: Ayat Dulu memakai API Layanan Aksesibilitas Android untuk mengetahui kapan Anda membuka aplikasi yang Anda pilih sendiri (misalnya Instagram), lalu menampilkan satu ayat Al-Qur'an atau kartu huruf hijaiyah sebelum aplikasi itu terbuka. Inilah fungsi utama aplikasi.

Apa yang dibaca: hanya nama paket aplikasi yang sedang tampil di layar (contoh: com.instagram.android), dari peristiwa perubahan jendela (TYPE_WINDOW_STATE_CHANGED).

Apa yang tidak dibaca: isi layar, teks yang Anda ketik, kata sandi, pesan, kontak, foto, atau riwayat penelusuran. Layanan dikonfigurasi dengan canRetrieveWindowContent="false", sehingga secara teknis tidak dapat membaca isi layar.

Ke mana datanya: nama paket hanya dibandingkan sesaat dengan daftar pilihan Anda di dalam HP. Nama paket tidak disimpan sebagai riwayat dan tidak dikirim ke mana pun.

Persetujuan: sebelum membuka Pengaturan Aksesibilitas, aplikasi menampilkan penjelasan ini dan meminta persetujuan Anda dengan tombol yang jelas. Anda dapat menolak dan tetap memakai aplikasi, serta mematikan layanan ini kapan saja di Pengaturan Android › Aksesibilitas.

Ayat Dulu bukan alat bantu khusus penyandang disabilitas.

1. Data stored on your phone

To work, the app keeps the following in your phone's internal storage. It never leaves your phone:

  • Settings: the apps you chose to gate, gate mode, daily target, free window, font size, translation language, transliteration, theme, and Quiet mode.
  • Learning progress: your reading position, Hijaiyah level, and number of completed readings (khatam).
  • Local statistics: verses and cards read, gates completed, how often each exit was used, active days, Hijrah Garden, and streak.
  • Translation-only mode: whether it is on and the end date you entered.
  • Today's gate log for the Help screen: the number of gates shown and skipped per reason (free time, not a proper place), the time of the last event, and when the service last connected. No app names; counts reset every day.

Data backup (optional): when you tap Settings › Save a backup, the data above (except the daily gate log) is copied to one JSON file in a place you choose through the Android file picker, for example Downloads or Google Drive. The app does not send that file anywhere; if you choose a cloud service, the file is subject to that service's policy. The file is only read back when you choose Restore from backup.

Ayah First does not keep a history of the apps you open. You can delete all of this data at any time via Android Settings › Apps › Ayah First › Storage › Clear data, or by uninstalling the app.

2. Accessibility Service (AccessibilityService API)

Why: Ayah First uses the Android Accessibility Service API to know when you open an app you selected yourself (for example Instagram), so it can show one Quran verse or one Arabic-letter card before that app opens. This is the core function of the app.

What is read: only the package name of the app currently on screen (for example com.instagram.android), from window-change events (TYPE_WINDOW_STATE_CHANGED).

What is not read: screen content, text you type, passwords, messages, contacts, photos, or browsing history. The service is configured with canRetrieveWindowContent="false", so it technically cannot read screen content.

Where it goes: the package name is only compared, on your phone, with your list of selected apps. It is not stored as a history and is not sent anywhere.

Consent: before opening Accessibility settings, the app shows this explanation in the app and asks for your consent with a clear button. You can decline and still use the app, and you can turn the service off at any time in Android Settings › Accessibility.

Ayah First is not an accessibility tool for people with disabilities.

4. Sharing

"Share summary" and the celebration card create text or an image on your phone and open the Android share menu. Nothing is sent unless you pick a destination app and send it yourself.

"Report a problem" on the Help screen prepares a message with your phone brand and model, Android version, app version, permission status and today's gate log. It is also sent only if you choose a destination (for example email or WhatsApp) and send it yourself.

5. Third parties

Ayah First contains no advertising, analytics, tracking, or other third-party SDKs that transmit data. The Quran text comes from the Tanzil Project (tanzil.net) and is bundled inside the app, not downloaded during use.

6. Children

Ayah First is not directed to children under 13 and collects no data from anyone, including children.

7. Security

Because data never leaves your phone, it is protected by your phone's own security (screen lock and Android's built-in encryption).

8. Changes

If a new feature changes how data is handled (for example a feature that needs the internet), this policy will be updated first and the effective date changed. Important changes will also be announced in the app.
